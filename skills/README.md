# Skills do projeto NEXA

As skills são checklists operacionais reutilizáveis. Elas complementam os agents.

## Como usar

Combine um agent com uma ou mais skills.

Exemplos:
- `agents/supabase.md` + `skills/revisar-seed.md`
- `agents/pedagogia.md` + `skills/validar-taxonomia.md`
- `agents/front.md` + `skills/implementar-tela.md`

## Skills disponíveis

- `revisar-seed.md`
- `validar-taxonomia.md`
- `criar-migration.md`
- `implementar-tela.md`
- `sincronizar-json-sql.md`
- `revisar-service.md`

## Regra prática

Agent define o papel.
Skill define o procedimento.
